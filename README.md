# ①課題名
接待じゃんけん 出世編

## ②課題内容（どんな作品か）
- 平成・令和世代には理解不能な、上司に負けるためのじゃんけん 勝ったら出世が遠のく。
- 田中係長と5回勝負して、機嫌がよければ昇進、ダメなら左遷されます

## ④アプリのログイン用IDまたはPassword（ある場合）

## ⑤工夫した点・こだわった点
- 前に作った接待じゃんけんを、視覚的におもしろくしたくてアップデート（というよりほぼ作り直し）しました
- よりめんどくさい人柄の演出を出したかったので、あいこも混ぜないと昇進できません。
負けすぎると「わざと負けてない？」と疑われるようにしました。
- 上司の顔の画像はChatGPTで生成、3種類作りました（ふつう・笑顔・怒り顔）
- 結果を辞令として出すようにしました。（左遷だと遠方の地域に飛ばされます）

## ⑥難しかった点・次回トライしたいこと（又は機能）
- 今回もAIにかなり助けてもらいました。自分だけではまだ作れないです
- 上司の画像が出なくて困りました（ファイル名相違でした）
- 画面を切り替えたら、すき間がなくなって詰まって見えるのをAIに見てもらい直してもらいました
- 次は上司を増やしたいです。まず課長を1人足してみたいです
